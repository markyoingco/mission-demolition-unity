# Mission Demolition

Physics-based slingshot puzzler where you knock down castle structures across selectable levels, with trajectory preview, shot tracking, and dynamic camera views.

## Features

- Projectile launching
- Physics-based collisions
- Level select and multi-level progression
- Trajectory preview and shot tracking
- Dynamic camera views
- Structure and target destruction

## Tech

- Unity
- C#

## Open in Unity

1. Open Unity Hub.
2. Add this project folder.
3. Use Unity 2022.3 LTS (project version: 2022.3.62f3).

## Course Context

Built for COSC 3550 Programming Computer Games coursework at Marquette University.
