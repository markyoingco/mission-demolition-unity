# Mission Demolition

Unity physics-based projectile game focused on aiming, launching, collisions, and target destruction.

## Features

- Projectile launching
- Physics-based collisions
- Rigidbody and Collider behavior
- Structure/target interaction
- Scene-based gameplay logic

## Tech Stack

- Unity
- C#
- Physics
- Rigidbody
- Colliders
- Scene Management

## Course Context

Built for COSC 3550 Programming Computer Games coursework at Marquette University.
